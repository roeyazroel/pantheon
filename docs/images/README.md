# Screenshots

The README's and the website's screenshots, taken by the game itself at 1600 × 900 from seed 1234
and saved as JPEG (quality 82). [DEVELOPMENT.md](../DEVELOPMENT.md#taking-the-readmes-screenshots)
shows how to take them, on a machine without a GPU too. Each was taken with these options, after `--seed=1234`:

| Image | Options |
| --- | --- |
| `pantheon.jpg` | `--pantheon=on --angel=off --quit-after-frames=50` |
| `talk.jpg` | `--gods-met=on --talk=2 --angel=off --advance-ticks=1200 --quit-after-frames=50` |
| `proposal.jpg` | `--gods-met=on --talk=3 --angel=off --advance-ticks=3000 --quit-after-frames=50` |
| `minds.jpg` | `--title-page=minds --quit-after-frames=50` |
| `angel-radiant.jpg` | `--angel=radiant --advance-ticks=1200 --quit-after-frames=50`, cropped to the angel (x 440–1130, y 160–500) |
| `angel-torn.jpg` | `--angel=torn --advance-ticks=1200 --quit-after-frames=50`, cropped the same way |
| `angel-fallen.jpg` | `--angel=fallen --advance-ticks=1200 --quit-after-frames=50`, cropped the same way |
| `angel-kind.jpg`, `angel-unformed.jpg`, `angel-stern.jpg` | `--angel=kind`, `--angel=unformed` or `--angel=stern`, with `--advance-ticks=1200 --quit-after-frames=50`, cropped the same way (the website only) |
| `village.jpg` | `--advance-ticks=9000 --camera-distance=110 --angel=off --quit-after-frames=50` |
| `title.jpg` | `--menu=on --quit-after-frames=60` |
| `creature.jpg` | `--focus=creature --angel=off --quit-after-frames=50` |
| `reward.jpg` | `--focus=creature --judge=reward --camera-distance=30 --angel=off --advance-ticks=600 --quit-after-frames=36` |
| `fight.jpg` | `--meet=on --fight=on --focus=creature --angel=off --quit-after-frames=90` |
| `eruption.jpg` | `--disaster=eruption --angel=off --quit-after-frames=480` |
| `storm.jpg` | `--weather=hurricane --camera-distance=140 --angel=off --advance-ticks=600 --quit-after-frames=90` |
| `fire.jpg` | `--disaster=fire --camera-distance=220 --angel=off --advance-ticks=1500 --quit-after-frames=120` |
| `beast.jpg` | `--great-event=beast --angel=off --quit-after-frames=90` |
| `religion.jpg` | `--overlay=religion --camera-distance=1500 --weather=normal --angel=off --advance-ticks=3000 --quit-after-frames=50` |
| `diplomacy.jpg` | `--gods-met=on --diplomacy-panel=on --angel=off --advance-ticks=3000 --quit-after-frames=50` |
| `book.jpg` | `--book=world --angel=off --advance-ticks=3000 --quit-after-frames=50` |

No model was chosen, so the offline scribes wrote and spoke for the gods. The rival gods' names
come from the world's seed, so the same options give the same gods. What
happens in the frames before the screenshot depends on how fast the computer runs them, so a
retake is close to, but not always exactly, the same picture.
